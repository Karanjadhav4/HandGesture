🖐️🎚️ Hand Gesture Volume Control Project

Welcome to my Hand Gesture Volume Control System — an interactive computer-vision project that lets you control system volume using just your hand gestures! 🤯💻✨

Built using OpenCV, MediaPipe, and Python, this project shows how AI-powered gesture recognition can replace traditional input devices and create a seamless, touchless user experience. 🚀🤖

🌟 What This Project Does

🖐️ Detects hand landmarks in real-time

🔄 Tracks finger positions (Thumb + Index)

🎚️ Converts distance between fingers → Volume Level

🎧 Controls system volume instantly

⚡ Works in real time with smooth UI feedback

🚀 Key Highlights

🎯 Accurate finger tracking using MediaPipe Hand Tracking

🔊 Dynamic volume adjustment based on gesture distance

📹 Real-time webcam-based gesture recognition

📈 FPS counter for performance monitoring

💡 Clean, beginner-friendly Python code

🛠️ Tech Stack Used

🐍 Python

🎥 OpenCV

✋ MediaPipe

🔉 PyCaw (for system volume control)

💻 Webcam / Laptop Camera
